Règles de confidentialité

Dernière mise à jour : 17 octobre 2026.

Short Bot est utilisé uniquement par son propriétaire, pour publier ses propres vidéos sur ses propres comptes YouTube et Instagram.

Données utilisées

Short Bot utilise l'API YouTube Data avec l'autorisation youtube.upload, uniquement pour envoyer des vidéos sur les chaînes du propriétaire, et l'API Instagram avec les autorisations instagram_business_basic et instagram_business_content_publish, uniquement pour publier des Reels sur les comptes du propriétaire. Il ne lit, ne collecte, ne vend ni ne partage aucune donnée personnelle de qui que ce soit. Les jetons d'accès sont stockés de façon chiffrée dans les secrets GitHub du propriétaire.

Services tiers

Short Bot utilise les services d'API YouTube. Voir les conditions d'utilisation de YouTube et les règles de confidentialité de Google. L'accès peut être révoqué à tout moment sur la page des autorisations de votre compte Google.

Pour Instagram, voir la politique de confidentialité de Meta. L'accès peut être révoqué dans les paramètres Instagram, rubrique Applications et sites web.

Suppression des données

Short Bot ne conserve aucune donnée personnelle. Pour supprimer ses jetons d'accès, il suffit de révoquer l'accès depuis Google ou Instagram (voir ci-dessus) : ils cessent alors de fonctionner.

Contact

Pour toute question, ouvrez une demande sur la page GitHub de Benjamin-DRX.

Privacy policy

Last updated: October 17, 2026.

Short Bot is used only by its owner, to publish the owner's own videos to the owner's own YouTube and Instagram accounts. It uses the YouTube Data API with the youtube.upload scope only, and the Instagram API with the instagram_business_basic and instagram_business_content_publish permissions only. It does not read, collect, sell or share anyone's personal data. Access tokens are stored encrypted in the owner's GitHub secrets.

Short Bot uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google account permissions. For Instagram, see the Meta Privacy Policy; access can be revoked in Instagram settings, under Apps and websites.

Data deletion: Short Bot stores no personal data. Revoking access from Google or Instagram makes its access tokens stop working.
